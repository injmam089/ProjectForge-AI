## Contributing Screenshots

If you would like to contribute screenshots:

1. Run the application locally (see [Getting Started](../../README.md#getting-started-local-development))
2. Capture the relevant UI at 1440px or wider viewport width
3. Save as PNG in this directory using the filename from the table above
4. Open a pull request — see [CONTRIBUTING.md](../../CONTRIBUTING.md)
