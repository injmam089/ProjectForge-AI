# Development Plan

1. Foundation: repo, frontend/backend scaffolds, PostgreSQL, Docker Compose, health check.
2. Authentication: registration, login, hashing, authorization, tests.
3. Project management: CRUD and ownership.
4. AI requirement engine: structured analysis, clarification, validation.
5. Requirements workspace: review, editing, approval.
6. Markdown generation: document planner and generators.
7. Markdown workspace: preview, editor, save, AI edit.
8. ZIP export: document selection, safe archive, download.
9. Dashboard and project history.
10. Testing and security hardening.
11. Deployment.
12. UX, accessibility, performance, polish.

Do not begin a later phase before the current phase builds and its relevant tests pass.
