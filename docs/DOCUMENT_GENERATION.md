# Document Generation

Generate documents only after explicit requirements approval.

## Potential core documents
`README.md`, `PROJECT_REQUIREMENTS.md`, `PROJECT_GOALS.md`, `FEATURES.md`, `TECH_STACK.md`, `ARCHITECTURE.md`, `DATABASE.md`, `API_SPECIFICATION.md`, `SECURITY.md`, `DEVELOPMENT_PLAN.md`, `TESTING.md`, `DEPLOYMENT.md`, `AI_BUILD_INSTRUCTIONS.md`.

## Conditional documents
Examples: `MODEL_REQUIREMENTS.md`, `DATASET.md`, `ML_PIPELINE.md`, `HARDWARE.md`, `SENSORS.md`, `PROTOCOLS.md`, `MOBILE_REQUIREMENTS.md`.

The document planner must select only relevant files. Every generator consumes the approved specification. Validate output, filenames, links, consistency, and secrets before saving/exporting.
