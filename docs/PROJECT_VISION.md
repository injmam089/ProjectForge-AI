# Project Vision

ProjectForge AI converts a rough software idea into complete, reviewable requirements and, only after user approval, a consistent set of Markdown project documents that can be exported as a ZIP.

## Core flow
Idea → Analysis → Clarification → Requirements → Review → Approval → Specification JSON → Markdown → ZIP.

## V1 users
Students, individual developers, hackathon teams, freelancers, and small development teams.

## V1 scope
Project creation, AI requirement analysis, clarification, structured requirements, review/edit/approval, relevant Markdown generation, Markdown editing, AI-assisted document editing, ZIP export, dashboard, and authentication.

## Explicitly out of scope
Automatic code generation, GitHub repository creation, autonomous deployment, team collaboration, vector databases, custom model fine-tuning, and multi-agent coding orchestration.
